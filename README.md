# 📝 Text or Die Game (Pygame)

เกมแนวพิมพ์คำตอบเพื่อเอาชีวิตรอด (**Text or Die**) พัฒนาขึ้นด้วยภาษา Python และไลบรารี Pygame โดยผู้เล่นจะต้องพิมพ์คำตอบให้ถูกต้องและยาวพอเพื่อสร้างฐานหรือสิ่งกีดขวางไม่ให้จมน้ำ!

---

## ✨ Features (คุณสมบัติของเกม)
- **Interactive Gameplay:** เกมเพลย์สนุกสนานและท้าทายความเร็วในการพิมพ์
- **Pygame Graphics:** กราฟิก 2 มิติที่เรียบง่ายและเข้าใจง่าย
- **Dynamic Challenges:** คำถามและโจทย์ที่เปลี่ยนไปทดสอบคลังคำศัพท์และความไว

---

## 🛠️ Requirements (สิ่งที่ต้องมีก่อนติดตั้ง)
โปรดตรวจสอบให้แน่ใจว่าคุณได้ติดตั้งสิ่งเหล่านี้บนเครื่องของคุณแล้ว:
- Python (แนะนำเวอร์ชัน 3.8 ขึ้นไป)
- pip (ตัวจัดการแพ็กเกจของ Python)

---

## 🚀 Installation & Running (วิธีติดตั้งและรันเกม)

1. **Clone repository นี้ลงในเครื่องของคุณ:**
   ```bash
   git clone [https://github.com/maneekongritphichayaporn-creator/Text-Or-Die_Game_Pygame.git](https://github.com/maneekongritphichayaporn-creator/Text-Or-Die_Game_Pygame.git)

```

2. **เข้าไปยังโฟลเดอร์ของโปรเจกต์:**
```bash
cd Text-Or-Die_Game_Pygame

```


3. **ติดตั้งไลบรารีที่จำเป็น (Pygame):**
```bash
pip install pygame

```


4. **รันเกม:**
```bash
python main.py

```


*(หมายเหตุ: หากชื่อไฟล์หลักไม่ใช่ `main.py` ให้เปลี่ยนเป็นชื่อไฟล์สคริปต์หลัก เช่น `game.py`)*

---

## 🎮 How to Play (วิธีเล่นเกม)

1. อ่านคำถามที่ปรากฏขึ้นบนหน้าจอ
2. พิมพ์คำตอบที่ยาวที่สุดเท่าที่จะทำได้หรือตรงกับเงื่อนไขลงในช่องพิมพ์
3. กด Enter เพื่อยืนยันคำตอบ
4. ยิ่งคำตอบยาวหรือถูกต้อง จะช่วยต่อฐานให้สูงขึ้นเพื่อหนีน้ำ!
